
# 🌐 MyFlexBlog

O **MyFlexBlog** é um projeto criado para explorar e aplicar conceitos de **CSS Flexbox**. O objetivo foi desenvolver um site responsivo e flexível, garantindo uma distribuição eficiente dos elementos e um layout adaptável para diferentes tamanhos de tela.

---

## 📋 Descrição

Este projeto demonstra a utilização de **Flexbox** para:

- Distribuir espaços de maneira equilibrada entre os itens.
- Alinhar elementos, mesmo com tamanhos variados ou dinâmicos.
- Garantir responsividade sem comprometer a estrutura visual.

O resultado é um site moderno e adaptável, com foco na organização de conteúdo e boa experiência de usuário.

---

## 🚀 Tecnologias Utilizadas

- **HTML5**  
  Estruturação do conteúdo.

- **CSS3 (Flexbox)**  
  Estilização da página e criação de um layout responsivo.

---

## 🎯 Funcionalidades

- Layout responsivo utilizando Flexbox.
- Seções bem estruturadas para fácil navegação:
  - Sobre
  - Produtos
  - Preços
  - Qualidade
  - Newsletter
- Design limpo e adaptável a diferentes dispositivos.
